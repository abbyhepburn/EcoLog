# EcoLog 
#Tracks the user's activites via command-line interface.The user is able to log activities, get info on the activities, collect animals, get info on the animals, and view their overall points and what animals they've collected. Each activity logged allows the user to gain points and these can points unlock and grow multiple different animals. The user can also learn about how they can complete each activity and more about the endangered status of the animals featured in this program.
#Promotes sustainable behavior in a fun way through the collection of cute animals!
